# Простейший мессенджер на Flask

Простейший веб-мессенджер на Flask: пользователи, чаты, личные и групповые сообщения.

> Университетский проект по Python (ООП). Тема: «Разработка простейшего мессенджера на Flask».

# Зачем это нужно

В мессенджерах я постоянно теряюсь: личные диалоги, рабочие чаты и группы друзей перемешаны, а чтобы просто написать другу или обсудить что-то с группой, приходится переключаться между разными приложениями. Этот проект решает проблему: все пользователи, личные и групповые чаты и сообщения хранятся в одном веб-мессенджере на Flask. Он показывает, как устроен мессенджер изнутри — от регистрации и входа до ленты сообщений и дашборда с данными о нагрузке, трафике и спаме.

## Стек технологий

| Компонент | Технология |
|---|---|
| Язык | Python 3.11+ |
| Web-фреймворк | Flask |
| ORM | Flask-SQLAlchemy |
| БД | SQLite |
